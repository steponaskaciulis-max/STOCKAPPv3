# GitHub Desktop - Step by Step Guide

## Step 1: Download GitHub Desktop

1. Go to: **https://desktop.github.com/**
2. Click the big **"Download for macOS"** button
3. Open the downloaded file
4. Drag **GitHub Desktop** to your Applications folder
5. Open GitHub Desktop from Applications

## Step 2: Sign In

1. When GitHub Desktop opens, click **"Sign in to GitHub.com"**
2. Enter your GitHub username and password
3. Authorize GitHub Desktop if prompted

## Step 3: Add Your Repository

1. In GitHub Desktop, click **"File"** → **"Add Local Repository"**
2. Click **"Choose..."** button
3. Navigate to: `/Users/sk/Desktop/Cursor1/stock-watch-clean`
4. Click **"Add Repository"**

## Step 4: Push Your Code

1. You should see all your files listed in GitHub Desktop
2. At the bottom, you'll see:
   - **Summary**: "Add real stock data integration with refresh feature"
   - **Description**: (leave empty or add notes)
3. Click the **"Push origin"** button (top right)
4. Wait a few seconds - it will push to GitHub!

## Step 5: Verify

1. Go to: https://github.com/steponaskaciulis-max/STOCKAPPv3
2. You should see your updated files!
3. Vercel will automatically detect the changes and redeploy

## That's It! 🎉

Your code is now on GitHub and Vercel will update your site automatically!
